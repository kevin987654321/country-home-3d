# Country Home 3D — 純白鄉村風全室精細 3D 建築模型

依據原始建築平面圖 **1:1 公分級比例**（`853 × 820 cm`）與室內設計圖精細建立之互動式 WebGL / Three.js 3D 住宅模型。

## 特色重點

- **1:1 平面圖對位驗證**：內建正交俯視模式與原始平面圖疊圖透明度滑桿（`0%–100%`）及 3D 斜線尺寸標註系統。
- **純白鄉村風全室細部木作**：玄關法式八角復古花磚與 `240 cm` 懸空百葉端景鞋櫃、陶瓷農舍圍裙水槽廚具與壁爐造型抽油煙機、`200 × 90 cm` 圓角白橡木車枳大餐桌、東北角陽光閱讀單椅角落、主臥 `60 × 30 cm` 精準橢圓弧轉角層架衣櫃與雙衛浴。
- **右下角書房／次臥 1:1 設計圖極精細還原**：無縫包樑隱藏窗簾盒、正弦波立體抓褶落地簾、`17 cm` 深窗龕雙扇對開純白氣密窗、C1 內圓弧流線轉角書桌（含同曲率無把手抽屜與無線鍵鼠）、三層純白懸浮書架（含隱藏暖光洗牆燈帶、斜靠書列與 U 型雙口雕塑花器）及純白五爪輪流線環形扶手椅。
- **平滑立面隱藏過渡與多視角導覽**：支援 `3D 透視`、`正交俯視`、`第一人稱漫遊 (WASD)`，四向外牆具備防半截切牆與 `smoothstep` 平滑淡出／淡入過渡動畫，以及晨光／暖陽／夜燈三段光影氛圍。

## 本地啟動方式

```bash
npm install
npm run dev
```

建置正式版靜態檔案：

```bash
npm run build
```
